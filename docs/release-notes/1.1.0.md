**mvim is now uvim.** mvim 1.0.0 offers this version as an update and then fails to install it: the new name came with a new identifier, so to macOS and to the updater uvim is a different app. Download uvim from <https://github.com/celve/uvim/releases/latest>, and follow [Upgrading from mvim](https://github.com/celve/uvim#upgrading-from-mvim) to carry your settings over. The two permissions have to be granted again.
